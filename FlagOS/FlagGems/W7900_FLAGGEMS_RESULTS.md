# FlagGems AMD Radeon PRO W7900 性能测试报告

> 本报告全部数据来自物理 GPU 0（BDF `0000:03:00.0`），通过 `ROCR_VISIBLE_DEVICES=0` 锁定单卡，
> 测试期间机器上没有其它 GPU 负载。

## 1. 结论摘要

- 测试 10 类算子、FP16/BF16、5 个官方 core shape，共 100 个 shape/dtype 用例。
- Kernel 模式：71 个加速超过 2%，11 个近似持平，18 个慢超过 2%。
- Operator 模式：21 个加速超过 2%，10 个近似持平，69 个慢超过 2%。
- 71 个 Kernel 加速用例中，21 个保留实际调用收益，50 个被派发/启动开销抵消。
- Kernel 模式下 Sum、Softmax、Mean、LayerNorm、RMSNorm、BMM 六类算子中位 speedup 均不低于 1.18×；MM 接近持平（FP16 0.993×，BF16 0.946×）。
- Operator 模式只有 BMM 保持整体加速（1.15–1.19×），其余算子的中位 speedup 均回落到 1.0× 以下。
- 实际调用最值得保留：大型 Softmax、最大 LayerNorm、BMM。
- 小 shape 不适合当前 FlagGems AMD 路径：64×64 点算子在 Operator 模式仅 0.08–0.10×。

## 3. 测试范围与方法

- 算子：`mm`、`bmm`、`softmax`、`sum`、`mean`、`mul`、`sub`、`div`、`layer_norm`、`rms_norm`。
- Dtype：FP16、BF16。
- Shape：仓库官方 benchmark 内置 core shapes（`--level core`）；没有创建自定义 shape。
- 基线：原生 PyTorch ROCm。
- `speedup = PyTorch latency / FlagGems latency`；大于 `1.0×` 表示 FlagGems 更快。
- 分类：`>1.02×` 为加速，`0.98–1.02×` 为近似持平，`<0.98×` 为退化。
- 每种模式先预热，再正式运行 3 次；逐“算子 + dtype + shape”取三轮中位数。
- 算子/dtype 汇总先取 5 个官方 shape 的 speedup 中位数；绝对耗时取对应中位 speedup 代表 shape 的三轮中位耗时，保证三项指标来自同一 shape。
- 逐 shape 表同时保留三轮原始结果和三轮中位数。
- `--warmup 1000 --iter 500` 在本 benchmark 中是 1000 ms 预热预算和 500 ms 测量预算，不是固定调用次数。
- Kernel 模式通过 `triton.testing.do_bench(..., return_mode="median")` 主要测量 GPU 稳态时间。
- Operator 模式使用同步前后的墙钟时间，包含 Python、ATen/FlagGems 派发、Kernel launch 和 GPU 执行；不包含 `flag_gems.use_gems()` 上下文进入/退出本身。

### 3.1 正确性

本轮只执行了性能 benchmark，未运行官方完整正确性门禁。安装后做过一次冒烟校验：
`add`、`mul`、`softmax`、`sum`、`mm`、`layer_norm` 六个算子在 FP16/BF16 下与 PyTorch 结果比对，
相对误差均在 1% 容差内通过。

## 5. Kernel 模式测试与 FlagGems/PyTorch 比较

- 总计：加速 71/100，近似持平 11/100，退化 18/100。
- 95/100 个用例三轮 speedup 波动不超过 5%，重复性良好。
- LayerNorm、RMSNorm、BMM 三类算子在两种 dtype 的 5 个 shape 上全部加速。
- MM 呈 U 形：384² 为 1.06–1.09×，1024² 跌到最低的 0.71–0.85×，此后随 shape 增大回升，4096² 为 0.95–0.99×。
- Softmax、Sum、Mean 对 shape 高度敏感，最好与最差之间可差 3 倍以上。
- 退化集中在两处：`mean` 的 `[64,512,512]` 归约（0.77×）与 `softmax` 的一维 `[1048576]`（0.76–0.81×）。

## 6. Operator 模式测试与 FlagGems/PyTorch 比较

- 总计：加速 21/100，近似持平 10/100，退化 69/100。
- 45/100 个微秒级用例三轮 speedup 波动超过 5%，派发路径受调度与时钟噪声影响明显。
- 大型 Softmax `[64,512,512]` 保持 3.13–3.21×，`[1024,1024,1024]` 约 1.99–2.00×。
- 最大 LayerNorm 保留 2.40×（BF16）和 1.78×（FP16），其余四个小 shape 被派发开销压到 0.14–0.20×，中位因此落到 0.16× 附近。
- RMSNorm 只有 4096×4096 保留收益（1.38–1.44×）；最大的 `[1024,65536]` 受带宽限制回落到 0.90–0.92×，三个小 shape 低至 0.18×。
- BMM 是唯一在 Operator 模式下仍保持整体加速的算子（1.15–1.19×）。
- 大型 Mul/Sub/Div 接近持平；64×64 点算子仅 0.08–0.10×。

## 8. 限制与解释

1. 本报告是算子微基准，不等同于完整模型端到端吞吐。
2. Operator 模式使用 CPU 墙钟，微秒级用例容易受调度与时钟噪声影响；因此逐 shape 表同时给出三轮原始结果。
3. Kernel 与 Operator 使用不同计时机制，绝对 latency 不应跨模式直接相减；应重点比较各自相对 PyTorch 的 speedup。
4. AMD 后端当前没有专属算子实现和 C++ wrapper，使用的是通用 Triton kernel 及 AMD tuning/heuristics。
5. gfx1100 没有 arch 级候选表，`_amd/rdna4/` 下的调优结果不适用于本卡。
6. 本轮未执行官方完整正确性门禁，只做了六个算子的冒烟校验。
7. 测试只使用单卡，未覆盖多卡与通信场景。
8. 结论只适用于当前 FlagGems commit、ROCm/PyTorch/Triton 版本和官方 core shapes。

#!/usr/bin/env python3
"""Aggregate repeated FlagGems benchmark JSON files by median."""

from __future__ import annotations

import argparse
import csv
import json
from collections import defaultdict
from datetime import datetime, timezone
from pathlib import Path
from statistics import median
from typing import Any


METRICS = ("latency_base", "latency", "speedup", "tflops", "gbps_base", "gbps")


def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser()
    parser.add_argument("--inputs", nargs="+", type=Path, required=True)
    parser.add_argument("--output-dir", type=Path, required=True)
    return parser.parse_args()


def flatten_run(path: Path) -> dict[tuple[str, str, str, int, str], dict[str, Any]]:
    payload = json.loads(path.read_text())
    flattened: dict[tuple[str, str, str, int, str], dict[str, Any]] = {}

    for value in payload.values():
        for detail in value["details"]:
            mode = detail["mode"]
            op_name = detail["op_name"]
            dtype = detail["dtype"].removeprefix("torch.")
            for case_index, result in enumerate(detail["result"]):
                shape_key = json.dumps(
                    result["shape_detail"], sort_keys=True, separators=(",", ":")
                )
                key = (mode, op_name, dtype, case_index, shape_key)
                if key in flattened:
                    raise ValueError(f"Duplicate benchmark case in {path}: {key}")
                flattened[key] = {
                    "mode": mode,
                    "operator": op_name,
                    "dtype": dtype,
                    "case_index": case_index,
                    "shape_detail": result["shape_detail"],
                    **{metric: result.get(metric) for metric in METRICS},
                }

    return flattened


def aggregate(inputs: list[Path]) -> tuple[list[dict[str, Any]], list[dict[str, Any]]]:
    runs = [flatten_run(path) for path in inputs]
    expected_keys = set(runs[0])
    for path, run in zip(inputs[1:], runs[1:], strict=True):
        if set(run) != expected_keys:
            missing = expected_keys - set(run)
            extra = set(run) - expected_keys
            raise ValueError(f"Case mismatch in {path}: missing={missing}, extra={extra}")

    cases: list[dict[str, Any]] = []
    for key in sorted(expected_keys):
        records = [run[key] for run in runs]
        speedups = [record["speedup"] for record in records]
        latency_base_runs = [record["latency_base"] for record in records]
        latency_runs = [record["latency"] for record in records]
        median_speedup = median(speedups)
        spread_pct = (
            (max(speedups) - min(speedups)) / median_speedup * 100
            if median_speedup
            else None
        )
        aggregated = {
            "mode": records[0]["mode"],
            "operator": records[0]["operator"],
            "dtype": records[0]["dtype"],
            "case_index": records[0]["case_index"],
            "shape_detail": records[0]["shape_detail"],
            "latency_base_runs": latency_base_runs,
            "latency_runs": latency_runs,
            "speedup_runs": speedups,
            "speedup_spread_pct": spread_pct,
            "unstable_over_5pct": spread_pct is not None and spread_pct > 5,
        }
        for metric in METRICS:
            values = [record[metric] for record in records if record[metric] is not None]
            aggregated[f"median_{metric}"] = median(values) if values else None
        cases.append(aggregated)

    grouped: dict[tuple[str, str], list[dict[str, Any]]] = defaultdict(list)
    for case in cases:
        grouped[(case["operator"], case["dtype"])].append(case)

    summaries: list[dict[str, Any]] = []
    for (operator, dtype), group in sorted(grouped.items()):
        speedups = [case["median_speedup"] for case in group]
        spreads = [case["speedup_spread_pct"] for case in group]
        median_speedup = median(speedups)
        representative = min(
            group, key=lambda case: abs(case["median_speedup"] - median_speedup)
        )
        summaries.append(
            {
                "mode": group[0]["mode"],
                "operator": operator,
                "dtype": dtype,
                "cases": len(group),
                "representative_case_index": representative["case_index"],
                "representative_shape_detail": representative["shape_detail"],
                "median_latency_base": representative["median_latency_base"],
                "median_latency": representative["median_latency"],
                "median_speedup": median_speedup,
                "min_speedup": min(speedups),
                "max_speedup": max(speedups),
                "faster_over_2pct": sum(value > 1.02 for value in speedups),
                "near_parity_within_2pct": sum(0.98 <= value <= 1.02 for value in speedups),
                "slower_over_2pct": sum(value < 0.98 for value in speedups),
                "unstable_cases_over_5pct": sum(
                    case["unstable_over_5pct"] for case in group
                ),
                "median_case_spread_pct": median(spreads),
                "max_case_spread_pct": max(spreads),
            }
        )

    return cases, summaries


def write_outputs(
    output_dir: Path,
    inputs: list[Path],
    cases: list[dict[str, Any]],
    summaries: list[dict[str, Any]],
) -> None:
    output_dir.mkdir(parents=True, exist_ok=True)
    modes = {case["mode"] for case in cases}
    if len(modes) != 1:
        raise ValueError(f"Expected one benchmark mode, got: {sorted(modes)}")
    mode = modes.pop()
    payload = {
        "metadata": {
            "generated_at": datetime.now(timezone.utc).isoformat(),
            "aggregation": "median across repeated runs",
            "mode": mode,
            "classification": {
                "faster": "median speedup > 1.02",
                "near_parity": "0.98 <= median speedup <= 1.02",
                "slower": "median speedup < 0.98",
                "unstable": "speedup spread across runs > 5%",
            },
            "source_runs": [str(path) for path in inputs],
        },
        "operator_summary": summaries,
        "cases": cases,
    }
    (output_dir / "median_results.json").write_text(
        json.dumps(payload, indent=2, ensure_ascii=False) + "\n"
    )

    with (output_dir / "median_results.csv").open("w", newline="") as handle:
        fieldnames = [
            "mode",
            "operator",
            "dtype",
            "case_index",
            "shape_detail",
            "latency_base_runs",
            "latency_runs",
            "speedup_runs",
            "median_latency_base",
            "median_latency",
            "median_speedup",
            "median_tflops",
            "median_gbps_base",
            "median_gbps",
            "speedup_spread_pct",
            "unstable_over_5pct",
        ]
        writer = csv.DictWriter(handle, fieldnames=fieldnames)
        writer.writeheader()
        for case in cases:
            row = {name: case.get(name) for name in fieldnames}
            row["shape_detail"] = json.dumps(case["shape_detail"], separators=(",", ":"))
            for name in ("latency_base_runs", "latency_runs", "speedup_runs"):
                row[name] = json.dumps(case[name], separators=(",", ":"))
            writer.writerow(row)

    lines = [
        f"# FlagGems AMD Radeon GPU 0 {mode} benchmark medians",
        "",
        f"Three-run median using official core shapes, {mode} mode, "
        "1000 ms warmup and 500 ms measurement budgets.",
        "Absolute latencies are the three-run medians of the shape representing "
        "the median speedup in each operator/dtype group.",
        "",
        "| Operator | Dtype | PyTorch median ms | FlagGems median ms | Median speedup |",
        "|---|---:|---:|---:|---:|",
    ]
    for summary in summaries:
        lines.append(
            "| {operator} | {dtype} | {median_latency_base:.6f} | "
            "{median_latency:.6f} | {median_speedup:.3f}x |".format(**summary)
        )
    (output_dir / "median_summary.md").write_text("\n".join(lines) + "\n")


def main() -> None:
    args = parse_args()
    cases, summaries = aggregate(args.inputs)
    write_outputs(args.output_dir, args.inputs, cases, summaries)
    print(f"aggregated_runs={len(args.inputs)}")
    print(f"aggregated_cases={len(cases)}")
    print(f"operator_dtype_groups={len(summaries)}")
    print(f"mode={cases[0]['mode']}")
    for summary in summaries:

#!/usr/bin/env python3
"""Compare aggregated FlagGems kernel and operator benchmark results."""

from __future__ import annotations

import argparse
import csv
import json
from collections import defaultdict
from datetime import datetime, timezone
from pathlib import Path
from statistics import median
from typing import Any


def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser()
    parser.add_argument("--kernel", type=Path, required=True)
    parser.add_argument("--operator", type=Path, required=True)
    parser.add_argument("--output-dir", type=Path, required=True)
    return parser.parse_args()


def case_key(case: dict[str, Any]) -> tuple[str, str, int, str]:
    return (
        case["operator"],
        case["dtype"],
        case["case_index"],
        json.dumps(case["shape_detail"], sort_keys=True, separators=(",", ":")),
    )


def classify(speedup: float) -> str:
    if speedup > 1.02:
        return "faster"
    if speedup < 0.98:
        return "slower"
    return "near_parity"


def load_cases(path: Path, expected_mode: str) -> dict[tuple[str, str, int, str], dict[str, Any]]:
    payload = json.loads(path.read_text())
    mode = payload["metadata"].get("mode")
    if mode != expected_mode:
        raise ValueError(f"Expected {expected_mode} data in {path}, got {mode}")
    return {case_key(case): case for case in payload["cases"]}


def compare(
    kernel_path: Path, operator_path: Path
) -> tuple[list[dict[str, Any]], list[dict[str, Any]], dict[str, int]]:
    kernel_cases = load_cases(kernel_path, "kernel")
    operator_cases = load_cases(operator_path, "operator")
    if set(kernel_cases) != set(operator_cases):
        raise ValueError("Kernel and operator case sets do not match")

    comparisons: list[dict[str, Any]] = []
    for key in sorted(kernel_cases):
        kernel = kernel_cases[key]
        operator = operator_cases[key]
        kernel_speedup = kernel["median_speedup"]
        operator_speedup = operator["median_speedup"]
        kernel_class = classify(kernel_speedup)
        operator_class = classify(operator_speedup)
        comparisons.append(
            {
                "operator": kernel["operator"],
                "dtype": kernel["dtype"],
                "case_index": kernel["case_index"],
                "shape_detail": kernel["shape_detail"],
                "kernel_speedup": kernel_speedup,
                "operator_speedup": operator_speedup,
                "speedup_delta": operator_speedup - kernel_speedup,
                "operator_to_kernel_ratio": operator_speedup / kernel_speedup,
                "kernel_class": kernel_class,
                "operator_class": operator_class,
                "kernel_gain_retained": (
                    kernel_class == "faster" and operator_class == "faster"
                ),
                "kernel_gain_lost": (
                    kernel_class == "faster" and operator_class != "faster"
                ),
                "operator_unstable_over_5pct": operator["unstable_over_5pct"],
            }
        )

    grouped: dict[tuple[str, str], list[dict[str, Any]]] = defaultdict(list)
    for case in comparisons:
        grouped[(case["operator"], case["dtype"])].append(case)

    summaries: list[dict[str, Any]] = []
    for (operator, dtype), group in sorted(grouped.items()):
        kernel_speedups = [case["kernel_speedup"] for case in group]
        operator_speedups = [case["operator_speedup"] for case in group]
        kernel_median_speedup = median(kernel_speedups)
        operator_median_speedup = median(operator_speedups)
        summaries.append(
            {
                "operator": operator,
                "dtype": dtype,
                "cases": len(group),
                "kernel_median_speedup": kernel_median_speedup,
                "operator_median_speedup": operator_median_speedup,
                "operator_minus_kernel_median": (
                    operator_median_speedup - kernel_median_speedup
                ),
                "median_case_speedup_delta": median(
                    case["speedup_delta"] for case in group
                ),
                "kernel_faster_cases": sum(
                    case["kernel_class"] == "faster" for case in group
                ),
                "operator_faster_cases": sum(
                    case["operator_class"] == "faster" for case in group
                ),
                "kernel_gains_retained": sum(
                    case["kernel_gain_retained"] for case in group
                ),
                "kernel_gains_lost": sum(case["kernel_gain_lost"] for case in group),
                "operator_unstable_cases": sum(
                    case["operator_unstable_over_5pct"] for case in group
                ),
            }
        )

    totals = {
        "cases": len(comparisons),
        "kernel_faster_cases": sum(
            case["kernel_class"] == "faster" for case in comparisons
        ),
        "operator_faster_cases": sum(
            case["operator_class"] == "faster" for case in comparisons
        ),
        "kernel_gains_retained": sum(
            case["kernel_gain_retained"] for case in comparisons
        ),
        "kernel_gains_lost": sum(case["kernel_gain_lost"] for case in comparisons),
        "operator_unstable_cases": sum(
            case["operator_unstable_over_5pct"] for case in comparisons
        ),
    }
    return comparisons, summaries, totals


def write_outputs(
    output_dir: Path,
    kernel_path: Path,
    operator_path: Path,
    comparisons: list[dict[str, Any]],
    summaries: list[dict[str, Any]],
    totals: dict[str, int],
) -> None:
    output_dir.mkdir(parents=True, exist_ok=True)
    payload = {
        "metadata": {
            "generated_at": datetime.now(timezone.utc).isoformat(),
            "kernel_source": str(kernel_path),
            "operator_source": str(operator_path),
            "classification": {
                "faster": "median speedup > 1.02",
                "near_parity": "0.98 <= median speedup <= 1.02",
                "slower": "median speedup < 0.98",
            },
        },
        "totals": totals,
        "operator_summary": summaries,
        "cases": comparisons,
    }
    (output_dir / "mode_comparison.json").write_text(
        json.dumps(payload, indent=2, ensure_ascii=False) + "\n"
    )

    with (output_dir / "mode_comparison.csv").open("w", newline="") as handle:
        fieldnames = [
            "operator",
            "dtype",
            "case_index",
            "shape_detail",
            "kernel_speedup",
            "operator_speedup",
            "speedup_delta",
            "operator_to_kernel_ratio",
            "kernel_class",
            "operator_class",
            "kernel_gain_retained",
            "kernel_gain_lost",
            "operator_unstable_over_5pct",
        ]
        writer = csv.DictWriter(handle, fieldnames=fieldnames)
        writer.writeheader()
        for comparison in comparisons:
            row = {name: comparison.get(name) for name in fieldnames}
            row["shape_detail"] = json.dumps(
                comparison["shape_detail"], separators=(",", ":")
            )
            writer.writerow(row)

    lines = [
        "# FlagGems kernel vs operator mode",
        "",
        (
            f"Across {totals['cases']} official shape/dtype cases, "
            f"{totals['kernel_faster_cases']} were faster in kernel mode and "
            f"{totals['operator_faster_cases']} remained faster in operator mode."
        ),
        (
            f"Retained kernel gains: {totals['kernel_gains_retained']}; "
            f"lost after dispatch overhead: {totals['kernel_gains_lost']}; "
            f"operator cases with >5% run spread: {totals['operator_unstable_cases']}."
        ),
        "",
        "| Operator | Dtype | Kernel median | Operator median | Delta | Kernel faster | Operator faster | Retained | Lost | Unstable |",
        "|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|",
    ]
    for summary in summaries:
        lines.append(
            "| {operator} | {dtype} | {kernel_median_speedup:.3f}x | "
            "{operator_median_speedup:.3f}x | "
            "{operator_minus_kernel_median:+.3f} | "
            "{kernel_faster_cases} | {operator_faster_cases} | "
            "{kernel_gains_retained} | {kernel_gains_lost} | "
            "{operator_unstable_cases} |".format(**summary)
        )
    (output_dir / "mode_comparison.md").write_text("\n".join(lines) + "\n")


def main() -> None:
    args = parse_args()
    comparisons, summaries, totals = compare(args.kernel, args.operator)
    write_outputs(
        args.output_dir,
        args.kernel,
        args.operator,
        comparisons,
        summaries,
        totals,
    )
    print(json.dumps(totals, sort_keys=True))
    for summary in summaries:
        print(
            f"{summary['operator']:12} {summary['dtype']:8} "
            f"kernel={summary['kernel_median_speedup']:.3f}x "
            f"operator={summary['operator_median_speedup']:.3f}x "
            f"lost={summary['kernel_gains_lost']}"
        )


if __name__ == "__main__":
    main()
