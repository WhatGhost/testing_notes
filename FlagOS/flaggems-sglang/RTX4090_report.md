- 理论峰值来自 [NVIDIA Ada 架构白皮书](https://images.nvidia.com/aem-dam/Solutions/geforce/ada/nvidia-ada-gpu-architecture.pdf)，不含稀疏，按标称加速频率 2520 MHz 计算。算力和 SM 频率成正比，性能测试期间的中位频率比标称高 4%；显存带宽由显存频率决定，不受影响。

- 本卡的 SM 数、L2、显存容量和频率由 nvidia-smi 和 PyTorch 查询，见 `env.txt`；性能测试期间的频率取自 `gpu1_monitor.csv`、`perf_kernel_run3/gpu1_monitor.csv` 中 GPU 利用率大于 0 的采样。

## 概要

- 正确性：56 个算子、458 个用例，通过 458 个，全部通过。
- 性能：56 个算子、484 个形状。参考实现不带 Python 循环的 35 个算子，kernel 模式加速比的几何平均为 5.26×，operator 模式为 3.59×。
- 加速比小于 1 的测量点：kernel 模式 2 / 484，operator 模式 17 / 484。kernel 模式下每个算子的几何平均加速比都大于 1。
