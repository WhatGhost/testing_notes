### GPU 硬件参数

官方规格出自 [AMD 官网的 W7900D 规格页](https://www.amd.com/zh-cn/products/graphics/workstations/radeon-pro/w7900d.html)，带上标的几项见表下说明；算力为不含结构化稀疏的稠密峰值。「本机」一列是被测这张卡上驱动报告的值（KFD 拓扑、`env.txt`）和测试期间的监控数据，监控数据的统计方法同 W7900D_testing.md「运行情况」。

| 架构 | RDNA 3 | gfx1100 |
| 计算单元 | 96 CU（6144 个流处理器） | 96 CU |
| wavefront、LDS | - | wave32，每个 workgroup 的 LDS 为 64 KiB |

| 缓存 | Infinity Cache 96 MB | Infinity Cache 96 MB，L2 6 MB |

- 型号依据：PCI 设备号 `1002:744b`、修订号 `00`，AMD 维护的 libdrm 型号表（`amdgpu.ids`）中为 "AMD Radeon Pro W7900D"，pci-ids 数据库中为 "Navi 31 [Radeon Pro W7900D]"（W7900 为 `1002:7448`）；VBIOS 为 113-D7070910-100。本机的 `pci.ids` 和 `amdgpu.ids` 版本较旧，都没有收录这个设备号：`lspci` 只显示 "Device 744b"，rocm-smi 和 PyTorch 显示的是通用名 "AMD Radeon Graphics"。
- ¹ 官网没有列加速频率，2156 MHz 出自第三方资料（[videocardz](https://videocardz.net/amd-radeon-pro-w7900d)），与官网的 53 TFLOPS 相符：96 CU × 每个 CU 每周期 256 FLOP（双发射）× 2156 MHz ≈ 53 TFLOPS。
- ² AMD 的 FP32 峰值按双发射计算。Triton 生成的代码很少用到双发射，按单发射的 26.5 TFLOPS 估计更接近实际。
- ³ 官网只列了 FP16 矩阵。RDNA 3 上 BF16、INT8 矩阵运算与 FP16 同速，这两项据此推算（W7900 的官方规格中 INT8 与 FP16 矩阵同为 123）。
- ⁴ 驱动报告的功耗上限低于官方 TBP，两者的统计范围可能不同，本次没有核实。

## 概要

- 正确性：56 个算子、458 个用例，通过 455 个，未全部通过的算子：`chain_speculative_sampling`、`fused_moe_router_tensorcore`。`silu_and_mul_masked` 为补跑结果（‡）。
- 性能：56 个算子、484 个形状。参考实现不带 Python 循环的 35 个算子，kernel 模式加速比的几何平均为 5.36×，operator 模式为 3.71×。
- 加速比小于 1 的测量点：kernel 模式 4 / 484，operator 模式 19 / 484。kernel 模式下每个算子的几何平均加速比都大于 1。
